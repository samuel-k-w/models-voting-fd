## Color Usage by Component

### Buttons
```
Primary Button:
  Default: Primary (#2563eb) on white
  Hover:   Primary-Hover (#1d4ed8) with glow
  Active:  Primary-Active (#1e40af) scaled down
  Disabled: Muted (#f1f5f9) text
  
Outline Button:
  Default: Border Primary, text Primary
  Hover:   Background Primary-Light
  Active:  Background Primary-100
  Disabled: Border border, text muted-foreground
  
Danger Button:
  Default: Error (#dc2626) on white
  Hover:   Error-Hover (#b91c1c) with glow
  Disabled: Muted background
```

### Cards
```
Default Card:
  Background: background (#ffffff)
  Border:     border (#e2e8f0)
  Shadow:     shadow-sm
  Hover:      Border-Strong + shadow-md
  
Selected Card:
  Background: Primary-Light (#dbeafe)
  Border:     Primary (#2563eb), 2px
  Ring:       4px Primary-100
  Shadow:     shadow-md
  
Elevated Card:
  Background: background
  Border:     border
  Shadow:     shadow-md (baseline)
```

### Inputs
```
Default:
  Background: background
  Border:     border
  Text:       foreground
  
Focus:
  Border:     primary
  Ring:       3px Primary-Light
  
Error:
  Border:     error, 2px
  Ring:       3px Error-Light
  
Disabled:
  Background: muted
  Border:     border
  Text:       muted-foreground
```

## Quick Reference - CSS Variables

```css
/* Backgrounds */
var(--background)
var(--background-secondary)
var(--background-tertiary)

/* Text */
var(--foreground)
var(--foreground-secondary)
var(--foreground-tertiary)

/* Borders */
var(--border)
var(--border-strong)
var(--border-hover)

/* Primary Scale */
var(--primary-50) through var(--primary-dark)

/* Semantic */
var(--success)  var(--error)  var(--warning)  var(--info)
var(--success-light)  var(--error-light)  etc.

/* Medals */
var(--rank-1-gold)  var(--rank-2-silver)  var(--rank-3-bronze)

/* Effects */
var(--shadow-sm) ... var(--shadow-2xl)
var(--glow-sm)  var(--glow-md)  var(--glow-lg)
```
